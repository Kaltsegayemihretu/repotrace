WHAT THIS SHOWS

Real evidence, with its limits

RepoTrace reads the code of a project without running it. It does not upload, edit, or execute your repository.

  • Search matches words in names, paths, comments and code. It is not an AI answer.
  • Connections are the analyzer’s recorded links. “Sure” means the call is written in the code; “maybe” means one step depends on an assumption. Neither proves the code runs.
  • Change review and test lists come from the comparison you chose. Commands are copied, never executed here.
  • History is a hint, not a dependency. Missing links and missing tests are not proof of safety.

RAG, live repository loading, architecture checks and branch-conflict analysis are not connected in this prototype.

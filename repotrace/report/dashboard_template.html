What RepoTrace does

You pick two saved versions of a Python project. RepoTrace finds the functions that changed between them, then looks for other code that uses those functions, directly or through other functions. Those are the places worth checking after your change.

What it does not do

It never runs your code and never changes your files. It cannot prove that something will break or that something is safe. Python can decide at run time what to call, so some real callers cannot be found by reading code. An empty result never means “safe”.

How sure is each line?

● SureThe code text shows this call. It is not proven to run, but there is no doubt about the link. ◐ MaybeProbably a real call, but it depends on an assumption, such as what type an object has. Treat it as a hypothesis and check it. ○ Name onlySome call has the same name, but the analysis could not tell what it runs. This is the weakest evidence. It exists so that callers it could not follow are not silently lost.

Words used on this page

Function
A named piece of code, such as calculate_total. Inside a class it is called a method.
Caller
A function that uses another one. If you change a function, its callers are the places that may behave differently.
Steps away
How far a caller is from the changed function. Direct callers use it themselves. Two steps away means they use something that uses it.
Decorator
A line starting with @ that wraps a function. Changing a decorator affects every function it wraps.
Value (constant)
A fixed setting such as TAX = 1.15. Changing it affects every function that reads it.
Test code
Functions whose job is to test other code. They are real callers, but you may want to hide them to see your own code first.
